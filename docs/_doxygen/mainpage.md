# TMC5160 Driver API reference {#mainpage}

The classes, members and types of the HardFOC TMC5160 / TMC5130 driver, generated from the headers.

Start with tmc51x0::TMC51x0, the driver and its subsystems, and tmc51x0::SpiCommInterface or
tmc51x0::UartCommInterface, the interface your platform port implements. The configuration is
tmc51x0::DriverConfig; every call returns a tmc51x0::Result.

The guides, with examples that compile, are on the documentation site: <a href="../">TMC5160 Driver
documentation</a>.
