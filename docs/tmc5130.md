# TMC5130

What changes when the driver talks to a TMC5130 instead of a TMC5160, and what to watch for.

The TMC5130 is the TMC5160's sibling with integrated MOSFETs: the same motion controller, the same SPI and UART
interfaces and, for the registers both have, the same register map. The TMC5160 datasheet describes it as the
software-compatible part for designs up to 1.4 A of motor current.

## Detection

`Initialize()` reads the version field of `IOIN` (bits 31..24) and stores it:

| Chip | `IOIN.VERSION` | Constant |
| --- | --- | --- |
| TMC5130 | `0x11` | `tmc51x0::ChipVersion::TMC5130` |
| TMC5160 | `0x30` | `tmc51x0::ChipVersion::TMC5160` |

`status.GetChipVersion()` returns it afterwards. An unreadable version is treated as a TMC5160.

## What differs

| Feature | TMC5160 | TMC5130 | What the driver does |
| --- | --- | --- | --- |
| Power stage | External MOSFETs, `DRV_CONF`, `SHORT_CONF` | Integrated MOSFETs | Writes the power-stage registers on both |
| Current scaling | `GLOBAL_SCALER` (0x0B) | No `GLOBAL_SCALER` | Skips `GLOBAL_SCALER` once the chip is detected as a TMC5130 |
| Motor current | 1 A to several 10 A, set by R<sub>SENSE</sub> | Up to about 1.4 A | Calculates `IRUN` / `IHOLD` as for the TMC5160 |
| Supply, pinout | This site's [Hardware](hardware.md) page | TMC5130 datasheet | n/a |

Everything else (ramps, units, StallGuard2, CoolStep, StealthChop, encoder, reference switches, daisy chains and
UART nodes) works the same way.

!!! warning "Set the TMC5130's currents yourself"
    The automatic current calculation chooses `IRUN` for a `GLOBAL_SCALER` the TMC5130 does not have, so the coil
    current ends up higher than `run_current_ma`, by up to 256 / `GLOBAL_SCALER`. After `Initialize()`, set
    `IRUN` and `IHOLD` for your sense resistor with `motorControl.SetCurrent(irun, ihold)`, using the TMC5130
    datasheet's current formula. Also, the first `Initialize()` writes `GLOBAL_SCALER` before it reads the chip
    version.

## Checks that still say TMC5160

`status.VerifySetup()` expects version `0x30` and logs a mismatch warning on a TMC5130. Log tags read `TMC5160`
on both chips. Neither changes behaviour.
